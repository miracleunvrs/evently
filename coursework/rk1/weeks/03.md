# Неделя 3 Программа на Rust

**Задание силлабуса:** написать небольшую CLI-программу с конструкциями Rust, необходимыми при работе с Solana.

**Сделано:** модель события с ограничением мест и билетом однократного использования. Используются struct, enum, Vec, Result, итераторы и изменяемое заимствование. Проверены переполнение вместимости, дубль регистрации, повторный вход и неизвестный гость.

**Код:** `cli/src/main.rs`.
**Доказательства:** `evidence/rust-cli.txt`, `evidence/rust-tests.txt`.

**Запуск из корня репозитория:** `cargo run --manifest-path coursework/rk1/Cargo.toml -p evently-cli -- demo 2`; затем `cargo test --manifest-path coursework/rk1/Cargo.toml -p evently-cli`.
