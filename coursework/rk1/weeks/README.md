# Evently до РК1 по неделям

Каждый файл ниже соответствует одному заданию из предоставленного силлабуса.
Полные результаты и пояснения сохранены в отдельных Word-отчётах папки
`По_неделям/` комплекта сдачи. Все пути здесь указаны относительно `coursework/rk1/`.
На второй странице каждого Word-отчёта находится скриншот проверки. Отдельные
JPG лежат в `evidence/screenshots/`; для недели 2 также приложен прямой снимок
Solana Explorer. Снимки недель 1 и 3–8 отображают сохранённые локальные
результаты, а не выдают их за действия в Devnet. Страницы для снимков можно
пересоздать через `python3 scripts/build-evidence-pages.py`.

Локальные доказательства нельзя выдавать за Devnet. Для полной сдачи нужно получить
тестовые SOL, выполнить собственный перевод недели 1 и деплой недели 4 в Devnet.
После этого выполнить клиент для недель 5–7 в Devnet и обновить отчёты.
